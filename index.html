Prerequisites

Check your system before you download anything. Versions below were current on 19 September 2026; the download page is always the source of truth.

Check your Linux system

bash 
ldd --version | head -n1     # glibc must be 2.28 or newer
uname -m                     # x86_64 = x64, aarch64 = ARM64
cat /etc/os-release | head -n3

Ubuntu 20 or newer, Debian 10 or newer, Fedora 36 or newer and RHEL 8 or newer meet the glibc requirement.

Check your Windows system

PowerShell 
$env:PROCESSOR_ARCHITECTURE   # AMD64 = x64, ARM64 = ARM64
winver                        # shows your Windows version
Before you startYou need a Google account to sign in. Download only from antigravity.google; third-party mirrors and "cracked" builds are a common way to ship malware.

Desktop app (Antigravity 2.0)

The main agent workspace. Install this first if you want the full graphical experience.

  1. Download the installer

    Open the download page, choose the Windows tab under Antigravity 2.0, and click Download for x64 (or ARM64 on Windows on ARM). The file is named Antigravity-x64.exe or Antigravity-arm64.exe.

  2. Run the installer

    Double-click the file in your Downloads folder. If SmartScreen appears, confirm the publisher and the download source, then choose More info and Run anyway.

  3. Launch and sign in

    Open Antigravity from the Start menu. Sign in with your Google account in the browser window that opens, then return to the app.

  4. Open your first workspace

    Choose a project folder, describe a task to the agent and review the result before accepting changes.

  1. Download the tarball

    On the download page, choose the Linux tab under Antigravity 2.0 and download the x64 or ARM64 file. Both are named Antigravity.tar.gz.

  2. Extract to a folder you own

    A per-user location avoids needing root.

    bash 
    mkdir -p ~/.local/opt/antigravity
tar -xzf ~/Downloads/Antigravity.tar.gz -C ~/.local/opt/antigravity
ls ~/.local/opt/antigravity

  3. Find the launcher and start it

    The listing shows the extracted folder and its executable. Run the executable from a terminal the first time so any error is visible.

  4. Sign in

    A browser window opens for Google sign-in. Finish there and return to the app.

  5. Optional: add a menu entry and command

    Create a symlink to the executable in ~/.local/bin and a .desktop file in ~/.local/share/applications. Community installers automate this; see the note below.

Community installersSome GitHub projects package the official tarball as .deb, .rpm or a one-line script. They are not made by Google. Read any script before piping it to a shell, and prefer the official download when in doubt.

Command line (CLI)

Use Antigravity from your terminal, inside any codebase.

  1. Open PowerShell

    Use a normal (non-administrator) window.

  2. Run the official installer

    PowerShell 
    irm https://antigravity.google/cli/install.ps1 | iex

    Prefer Command Prompt? Use this instead:

    CMD 
    curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd

  3. Open a new terminal

    A new window picks up any PATH change the installer made. Then run the command name the installer printed.

To read the script before running it:

PowerShell 
irm https://antigravity.google/cli/install.ps1 -OutFile install.ps1
notepad install.ps1
.\install.ps1

  1. Run the official installer

    bash 
    curl -fsSL https://antigravity.google/cli/install.sh | bash

  2. Open a new shell

    A new session picks up any PATH change. Then run the command name the installer printed.

To read the script before running it (recommended on shared or production machines):

bash 
curl -fsSL https://antigravity.google/cli/install.sh -o install.sh
less install.sh
bash install.sh

Standalone IDE

A dedicated desktop application with integrated agent panels and a full execution workspace. It installs separately from the 2.0 desktop app.

  1. Download

    On the download page, scroll to Antigravity for IDEs, then Antigravity IDE (Standalone). Download the x64 or ARM64 file named Antigravity IDE.exe.

  2. Install and sign in

    Run the installer, launch Antigravity IDE from the Start menu and sign in with Google.

  1. Download

    In Antigravity IDE (Standalone), download the Linux x64 or ARM64 file named Antigravity IDE.tar.gz.

  2. Extract to its own folder

    bash 
    mkdir -p ~/.local/opt/antigravity-ide
tar -xzf "$HOME/Downloads/Antigravity IDE.tar.gz" -C ~/.local/opt/antigravity-ide
ls ~/.local/opt/antigravity-ide

  3. Launch and sign in

    Run the executable from the extracted folder and sign in with Google.

Python SDK

Build and orchestrate your own agents. The SDK is versioned separately (v0.1.16 when this was written), so expect API changes.

  1. Install Python and Git

    Get both from their official sites if python --version and git --version fail.

  2. Create an isolated environment

    PowerShell 
    git clone https://github.com/google-antigravity/antigravity-sdk-python
cd antigravity-sdk-python
python -m venv .venv
.\.venv\Scripts\Activate.ps1

  3. Install as the repository README directs

    The README lists the exact install command and authentication steps for the current release.

Verify and update

  • Launch each component you installed and confirm you can sign in.
  • Check the version in the app against the changelog.
  • Update the desktop app and IDE by downloading and running the newest installer over the old one. For the CLI, run the same install command again.
  • Update the desktop app and IDE by extracting a newer tarball into a fresh folder, then switching your launcher to it. For the CLI, run the same install command again.
  • Older builds are listed on the releases page if you need to roll back.

Troubleshooting

SmartScreen blocks the installer

Confirm you downloaded from antigravity.google, then choose More info and Run anyway. If your organization manages Windows, ask IT to allow the installer.

The CLI command is not found

Close every terminal and open a new one so the updated PATH loads. If it still fails, re-run the installer and read its final output for the install location.

The app will not start on Linux

Start it from a terminal and read the error. Two common causes: an old glibc (check with ldd --version) and Electron sandbox permissions. Do not disable the sandbox as a first step; look for guidance in the official docs or support page first.

Wrong architecture

Run uname -m. x86_64 needs the x64 build and aarch64 needs the ARM64 build.

Sign-in loops or fails

Confirm your default browser opens, that you are signed in to the right Google account there, and that a proxy or VPN is not blocking Google sign-in.

Where to get help

Publish this repository

This site is a static page, so GitHub Pages hosts it with no build step.

  1. Create the repository

    On GitHub, create a public repository named antigravity-setup-guide.

  2. Push the files

    bash or PowerShell 
    git init
git add .
git commit -m "Initial commit: Antigravity setup guide"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/antigravity-setup-guide.git
git push -u origin main

  3. Turn on Pages

    In the repository, open Settings, then Pages, and set Source to GitHub Actions. The included workflow deploys on every push to main.

  4. Replace the placeholders

    Search the repository for YOUR-USERNAME and replace it with your GitHub username.
