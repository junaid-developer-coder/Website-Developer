# Contributing

Thanks for helping keep this guide accurate.

## What to change
- Fix a wrong or outdated step: open an issue or pull request.
- Version numbers change often. Update the table in `index.html` (section `#prerequisites`) and note the date.
- Every install command must come from an official source (`antigravity.google`) or be clearly labelled as community-made.

## Pull requests
1. Fork the repository and create a branch.
2. Open `index.html` in a browser and test both the Windows and Linux views.
3. Keep commands copy-pasteable and tested on the OS they are shown for.
4. Describe what changed and link the official page that supports it.

## Do not add
- Links to unofficial download mirrors or modified builds.
- Google's official logo or other trademarked artwork. The logo in `assets/` is an original mark.
